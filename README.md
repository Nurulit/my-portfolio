# Nurulain Siddiqui — Portfolio

A responsive portfolio for Nurulain Siddiqui, Senior Front-End Engineer. Built with React, TypeScript, and Vite.

With 9+ years of experience, Nurulain specializes in React, TypeScript, and modern JavaScript, creating high-performance web experiences for global clients including FedEx and Abbott Laboratories.

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```

## Deploy to GitHub Pages

1. Push this project to a GitHub repository on the `main` branch.
2. In the repository, open **Settings → Pages** and set the build and deployment source to **GitHub Actions**.
3. The included workflow builds the site and publishes it whenever you push to `main`. You can also start it from the **Actions** tab.

The site uses a relative asset base so it works both at a custom domain and at a repository URL such as `username.github.io/repository/`.

The downloadable resume is served from `public/Nurulain-Siddiqui-Resume.docx`. Replace that file when updating the resume.
